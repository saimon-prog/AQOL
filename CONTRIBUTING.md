# Contribuer à AQOL

Merci de vouloir contribuer !

## Comment aider

### Code
1. Fork le dépôt
2. Crée une branche (`git checkout -b feature/ma-feature`)
3. Commit + push
4. Ouvre une Pull Request

### Sans code
- ⭐ Star le projet
- Ouvre une issue (bug ou idée)
- Partage AQOL dans tes réseaux (LinkedIn, X, Reddit r/QuantumComputing, r/MachineLearning…)
- Propose un notebook d’exemple réel

## Style de code
- Python 3.9+
- Type hints quand c’est clair
- Docstrings courtes en français ou anglais
- Tests dans `tests/`

## Questions
Utilise les **Discussions** GitHub plutôt que les issues pour les questions générales.
